# Takane Serve apps

Downloads for **Takane Serve**, QR ordering, kitchen display and zero-fee UPI for restaurants, by Takane System (Imphal, Manipur).

Get the app from **https://www.takanesystems.in/download**. This repository only hosts the installers; there is no source code here.

| App | For |
|---|---|
| Android (APK) | Kitchen, counter and waiter phones and tablets |
| Windows | Counter and kitchen computers; also runs the local hub |
| Mac | Counter and kitchen computers; also runs the local hub |
